# Curriculum 1.1

## Цель

Единый учебный позвоночник Chinese Study: пользователь сам выбирает стартовый уровень HSK 1–4, затем идёт по последовательной дорожке уроков. Диагностики нет.

## Источник стандарта

Curriculum 1.1 использует фиксированный словарь HSK 2.0 уровней 1–4 (1200 слов), поскольку именно эта градация соответствует привычным уровням HSK 1–4 и серии HSK Standard Course. Порядок лексики опирается на уроки HSK Standard Course 1–4 и затем делится на короткие блоки по 7–10 новых слов без разрушения тематических границ. Русские значения и пиньинь сверены по открытому набору `LiudmilaLV/json_hsk`; структура уроков — собственная.

Естественные фразы взяты из открытого набора [`no7z/hsk-sentences-audio`](https://github.com/no7z/hsk-sentences-audio) на закреплённом коммите. В выпуск включены только китайский текст, пиньинь, границы слов, тип и тема предложения; английские переводы и аудиофайлы не копируются. Условия и точная атрибуция приведены в [`ATTRIBUTION.md`](ATTRIBUTION.md).

Исходные справочные наборы используются только release-builder'ом и не вызываются приложением. В рабочем приложении загружается проверенный неизменяемый `curriculum-v1.json`.

## Модель

Level → Unit → Lesson → Objectives → Vocabulary → Grammar → Dialogue/Reading → Exercises → Review.

У каждого слова и грамматического элемента есть stable id, level, prerequisites и статус освоения пользователя.

## Урок

Обычный урок: 7–10 новых слов, 1 новая грамматическая конструкция, старый материал на повторение, 10–15 минут. Вместо служебных фраз вида «сегодня изучаем слово» используются естественные градуированные предложения.

Последовательность задания меняет способ извлечения материала: узнавание → аудирование без текста → грамматика по смыслу → чтение в контексте → порядок слов → пропуск → RU→中文 → воспроизведение естественной фразы по пиньиню. Это не восемь карточек: ученик слушает, восстанавливает и печатает. Свободных ответов без объективной проверки нет.

Ошибка никогда не блокирует переход: показываются правильный ответ, пиньинь и короткое объяснение, остаётся кнопка «Дальше». Ошибочная задача один раз возвращается позже в том же уроке. Итог хранит результат отдельно по навыкам и назначает слабым словам и грамматике ранний повтор.

## Повторение

SRS отвечает только за момент повторения. Curriculum отвечает за порядок нового материала. Смешанная сессия повторения проверяет шесть навыков: узнавание, аудирование, грамматику, чтение, порядок слов и воспроизведение фразы. В ней не больше пяти лексических задач плюс одна грамматическая; ошибочная задача может добавиться только как точечный повтор слабого навыка.

## Личные материалы

Мои материалы — параллельный слой. Система сверяет извлечённые слова с уже известными и curriculum. Пользователь может выбрать «Только новые слова» или «Полная тема». Личная лексика может попадать в SRS, но не должна нарушать зависимости основной грамматики.

## Старт

При первом запуске пользователь вручную выбирает HSK 1, HSK 2, HSK 3 или HSK 4. Уровень можно изменить позже. Предыдущие уровни считаются доступными как базовый словарь для примеров, но не требуют обязательного прохождения.

## Состав выпуска 1.1

`curriculum-v1.json` содержит 4 уровня, 20 разделов и 169 уроков: 149 уроков новой лексики и грамматики плюс 20 контрольных повторений. Покрыто 1200 слов и 149 грамматических конструкций. К 149 учебным урокам привязано 447 контекстов на основе 399 различных естественных фраз.

Проверка запускается командой:

```bash
python3 curriculum/validate_curriculum.py
```

Она создаёт `coverage-report.json` и `COVERAGE.md`, проверяет обязательные поля, уникальность идентификаторов, явные причины повторных словарных статей, порядок уроков, 7–10 новых слов, покрытие словаря и грамматики, зависимости и циклы, пиньинь, отсутствие одинаковых вариантов ответа, наличие трёх контекстов на урок и возможность восстановить фразу из её токенов.

`build_curriculum.py` — детерминированный инструмент выпуска. Помимо словаря и CSV порядка уроков он принимает `--sentences` и закрепляет коммит источника параметром `--sentence-source-commit`. Он не входит в пользовательский сценарий и не использует MiniMax. MiniMax может создавать вариативный личный материал, но не меняет порядок Curriculum и его грамматические зависимости.

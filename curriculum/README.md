# Curriculum 1.0

## Цель

Единый учебный позвоночник Chinese Study: пользователь сам выбирает стартовый уровень HSK 1–4, затем идёт по последовательной дорожке уроков. Диагностики нет.

## Источник стандарта

Curriculum 1.0 использует фиксированный словарь HSK 2.0 уровней 1–4 (1200 слов), поскольку именно эта градация соответствует привычным уровням HSK 1–4 и серии HSK Standard Course. Порядок лексики опирается на уроки HSK Standard Course 1–4 и затем делится на короткие блоки по 7–10 новых слов без разрушения тематических границ. Русские значения и пиньинь сверены по открытому набору `LiudmilaLV/json_hsk`; структура уроков — собственная.

Исходные справочные наборы используются только release-builder'ом и не вызываются приложением. В рабочем приложении загружается проверенный неизменяемый `curriculum-v1.json`.

## Модель

Level → Unit → Lesson → Objectives → Vocabulary → Grammar → Dialogue/Reading → Exercises → Review.

У каждого слова и грамматического элемента есть stable id, level, prerequisites и статус освоения пользователя.

## Урок

Обычный урок: 7–10 новых слов, 1 новая грамматическая конструкция, старый материал на повторение, 10–15 минут. Обязательные типы активности: узнавание лексики, аудирование, чтение/контекст, порядок слов, активный ответ. Ошибка никогда не блокирует переход: показывается правильный ответ, разбор и кнопка «Дальше».

## Повторение

SRS отвечает только за момент повторения. Curriculum отвечает за порядок нового материала. Повтор одного слова должен менять форму задания: значение, звук, контекст, пропуск, сборка, активный перевод.

## Личные материалы

Мои материалы — параллельный слой. Система сверяет извлечённые слова с уже известными и curriculum. Пользователь может выбрать «Только новые слова» или «Полная тема». Личная лексика может попадать в SRS, но не должна нарушать зависимости основной грамматики.

## Старт

При первом запуске пользователь вручную выбирает HSK 1, HSK 2, HSK 3 или HSK 4. Уровень можно изменить позже. Предыдущие уровни считаются доступными как базовый словарь для примеров, но не требуют обязательного прохождения.

## Состав выпуска 1.0

`curriculum-v1.json` содержит 4 уровня, 20 разделов и 169 уроков: 149 уроков новой лексики и грамматики плюс 20 контрольных повторений. Покрыто 1200 слов и 149 грамматических конструкций.

Проверка запускается командой:

```bash
python3 curriculum/validate_curriculum.py
```

Она создаёт `coverage-report.json` и `COVERAGE.md`, проверяет обязательные поля, уникальность идентификаторов, явные причины повторных словарных статей, порядок уроков, 7–10 новых слов, покрытие словаря и грамматики, зависимости и циклы, пиньинь и отсутствие одинаковых вариантов ответа.

`build_curriculum.py` — детерминированный инструмент выпуска. Он не входит в пользовательский сценарий и не использует MiniMax. MiniMax может создавать вариативный личный материал, но не меняет порядок Curriculum и его грамматические зависимости.

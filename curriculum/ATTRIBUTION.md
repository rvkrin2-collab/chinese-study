# Источники естественных контекстов

Поле `contexts` в `curriculum-v1.json` содержит отобранный поднабор китайских
предложений и пиньиня из проекта
[`no7z/hsk-sentences-audio`](https://github.com/no7z/hsk-sentences-audio),
коммит `857dfbab91027ebd97df01260e91b817cb6b4854`.

Исходный набор `dist/` распространяется по лицензии
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Производная
часть `contexts` распространяется на тех же условиях. Авторство исходного
набора: участники проекта `hsk-sentences-audio`.

В Chinese Study не копируются английские переводы, аудиофайлы и словарные
глоссы исходного набора. Сохраняются только необходимые для упражнений поля:
китайский текст, пиньинь, границы слов, тип предложения, тема и идентификатор
источника. Звук создаётся устройством пользователя через синтез речи.

Остальная структура Curriculum, русские переводы, порядок уроков и логика
упражнений не происходят из этого набора.
